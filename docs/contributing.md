# Contributing

We welcome contributions to DUITGOO! Please follow these steps:

1. **Fork and Clone**: Fork the repository and clone it locally.
2. **Setup**: Run `make setup` and `make migrate` to prepare your environment.
3. **Branch**: Create a feature branch (`git checkout -b feature/your-feature-name`).
4. **Development**: Follow the [Development Guide](development.md). Remember to work phase by phase.
5. **Testing**: Run `make test` and ensure all tests pass. For frontend UI changes, ensure you adhere to accessibility standards.
6. **Commit**: Use descriptive commit messages.
7. **Pull Request**: Submit a PR to the main repository. Ensure your PR description clearly explains the changes.
8. **Code Review**: Address any feedback from reviewers.
